Room setup

Three levels: add a room for each physical grow space (FC1, FC2, Shiitake Chamber, Oyster Room…), a zone inside it for each wall/section/shelf unit (Wall 1, Wall 2, Centre island…), then bays inside each zone. Each bay's rows become letters (A, B, C…) and slots run left to right. Edit any number any time — existing placements stay put.
